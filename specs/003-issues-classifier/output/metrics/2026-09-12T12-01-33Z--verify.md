## Worth to consider

- **Coverage** "start_mock() { ... sleep 10 }" — The ACCS assumes the mock's mock-data set is identical across the restart (same issue IDs, same count) since it diffs ISSUE_IDS from before and after. That relies on the mock's dataset being fixed rather than randomized per boot, which isn't stated anywhere in this spec but is inherited from spec 001/002's mock behaviour.
- **Coverage** "MOCK_SCRIPT="$(find_mock_script)"" — Discovery of the mock's pnpm script name is done by grepping `pnpm run` output for 'mock', so if package.json's script naming ever changes to not contain that substring, the ACCS breaks independent of classifier correctness. Worth a person double-checking the actual script name once.
