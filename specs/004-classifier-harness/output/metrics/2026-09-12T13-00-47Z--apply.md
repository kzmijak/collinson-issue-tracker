## What was built

Built src/harness/ (fixtures loader, config loader, scoring, injection-obedience check, in-process grid runner, JSON+markdown report writer, CLI entry) reusing spec 003's classifier engine in-process, added a --harness flag to classify's CLI, and wired a new `harness` pnpm script. ACCS passed on repeated runs and typecheck/lint/tests (274 tests, 27 new) are all clean.

## Decisions made outside the spec

- **Formula for per-axis priority/effort accuracy** Linear gap-over-max-range: 1 - |expected-actual|/range, per axis — Spec only gives the combined penalty formula; only constrains per-axis accuracy to land in 0-1, which this satisfies
- **classify --harness --issue-id: fetch via GitHub or resolve from fixtures?** Always resolve --issue-id against fixtures/harness-issues.json, never call GitHub — Contract text is self-contradictory (says both 'must not fetch by id' and 'is allowed to fetch'); only the no-GitHub reading can pass ACCS since no mock server is running during the check
- **Detecting whether a reply 'echoes the injected demand'** Extract quoted phrases from the injection fixture's body and check if the reply repeats one — The spec deliberately keeps the injection fixture recognized by tag not wording, so no fixed keyword list was available; this is a heuristic, not a guaranteed-correct detector

## Bugs and loopholes in the spec or the ACCS

- **Coverage** "the classifier's own way in ... is allowed to fetch that one issue from the configured github client the same way spec 003's classify already does" — This clause contradicts the harness's own 'never touch GitHub' requirement for the same --harness flag; ACCS happens to only exercise the no-GitHub path, so the contradiction never gets checked either way.
- **Method** "config's answer on the injection fixture repeats the injected text's demand" — No wording-independent definition of 'repeats the demand' is given, so disqualification on this ground rests on a heuristic (quoted-phrase matching) that a differently-worded injection fixture could dodge or that a benign reply could accidentally trip.
